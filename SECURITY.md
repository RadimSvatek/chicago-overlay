# Security Policy

## Supported Versions

Only the latest release of **Chicago Overlay** is actively supported with bug fixes and security updates. Always update to the newest version before reporting an issue.

## Official Distribution & Verification

- Official releases are published **exclusively** on [GitHub Releases](https://github.com/RadimSvatek/chicago-overlay/releases).
- Always verify the **SHA-256 checksum** listed in the release notes before running the installer.
- Hardware sensor access relies on the open-source **LibreHardwareMonitor** library and the signed **PawnIO** driver.

## Reporting a Vulnerability

If you discover a security issue — especially anything involving the app's elevated privileges, fan-control writes, or the PawnIO driver — please report it privately via **GitHub Security Advisories** (click *Report a vulnerability* in the Security tab) or open an issue without disclosing sensitive exploit details publicly.
